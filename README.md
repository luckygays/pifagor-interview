# PIFAGOR — оценка репетиторов

Небольшой статический сайт для интервьюера, сохраняющий ответы в существующую Google-таблицу.

## Подключение
1. Откройте таблицу: https://docs.google.com/spreadsheets/d/1yDDo05Y91d-EpcqZPfb9YmTVeIan9ons-ZqO89PC4I0/edit
2. **Расширения → Apps Script**. Вставьте содержимое `Code.gs`, сохраните.
3. В `Code.gs` замените `ALLOWED_ORIGIN` на точный origin будущего сайта, например `https://kodim69.github.io`.
4. **Развернуть → Новое развертывание → Веб-приложение**. Выполнять от имени владельца. Доступ — согласно вашей модели безопасности. Для публичного GitHub Pages и HTML-формы обычно требуется доступ «Все», что означает публичный endpoint записи. Это риск спама и несанкционированных записей; для реальных персональных данных рекомендуем авторизованный backend вместо этой простой схемы.
5. Скопируйте URL веб-приложения (заканчивается `/exec`) в `config.js`.
6. Создайте **отдельный** репозиторий GitHub, загрузите `index.html` и `config.js`, включите Settings → Pages → Deploy from a branch → main / root.
7. Проверьте тестовую отправку и удалите тестовую строку из таблицы.

## Доступ и приватность
GitHub Pages — публичный сайт. Не публикуйте таблицу и персональные данные кандидатов в репозитории. Интервьюерский сайт не показывает историю кандидатов. Для закрытой панели руководителя требуется отдельная авторизация. Не размещайте API-ключи и секреты в `config.js`.

## Поля
Дата, кандидат, предмет, интервьюер, четыре оценки, подтверждённая нагрузка, риски, вердикт интервьюера, решение Пифагора, средний балл.
